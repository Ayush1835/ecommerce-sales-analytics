REST API v1 Documentation

Programmatic JSON endpoints for ShopAnalytica platform

Overview

Base URL

/api/v1

Response Format

JSON envelope containing:

  • status (success/error)
  • message (string)
  • data (object/array)
  • timestamp (ISO-8601)

Status Codes

  • 200 OK
  • 400 Bad Request
  • 404 Not Found
  • 500 Server Error
GET

/api/v1/health

Health check & DB status

Parameters

None

Sample Response

{
  "status": "success",
  "message": "System is healthy",
  "data": {
    "db": "connected"
  },
  "timestamp": "2023-10-25T12:00:00Z"
}

/api/v1/products

List products

Query Parameters

NameTypeDescription
categoryStringFilter by category name
searchStringSearch product title
min_priceNumberMinimum price
max_priceNumberMaximum price
pageIntegerPage number (default 1)
per_pageIntegerItems per page (default 20)
sortStringprice_asc, price_desc, new

Sample Response

  "status": "success",
  "data": {
